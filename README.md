# User API – Node.js & Express

REST API sederhana menggunakan **Node.js**, **Express**, **Sequelize**, dan **SQLite**  
dengan fitur **Register, Login (JWT), dan Protected Route**.

Project ini dibuat mengikuti konsep REST API dan cocok untuk testing menggunakan **Postman**.
## 📦 Tech Stack
- Node.js
- Express.js
- Sequelize ORM
- SQLite
- JSON Web Token (JWT)
- Crypto (SHA256 hashing)

## ⚙️ Cara Instalasi
### 1️⃣ Clone / Extract Project
- git clone https://github.com/HansRF/Tugas13_API.git
- cd Tugas13_API

### 2️⃣ Install Dependency
- npm init -y
- npm install express sqlite3 bcryptjs jsonwebtoken

### 3️⃣ Jalankan Server
node index.js
